## The seam

- `pr/actions/open.ts:33-50` `openPr`: an existing open PR → `reportOrMarkReady`; else `createPr` (push, then
  `gh pr create`), result line `PR: #n …`. Writes nothing about the PR anywhere.
- `pr/actions/merge.ts:68-80` `recordMerge`: lands the merge line on main with `landOnMain`; spec from the
  target or `specOfBranch(view.headRefName)`.
- `pr/resolve.ts:47-56` `resolveGroupPr`: `specPrNumbers(pr-opening.md)` for `otherPrs` and the single-group
  fallback. Six callers pass `specStatesAt(...)` (open, merge, hold, rerun, wait, log, status).
- `commands/pr/status.ts`: sync; `buildReport(...).state` is the verdict (`green`), `.view` the settled view.
- `board/load.ts:96-106` `prLinks`: numbers per spec from base and every worktree's `pr-opening.md`.
  `fetchPrLists` (`pr/gh-lists.ts`) asks no `headRefOid` or `mergeCommit`; `PrRow` has neither.
- GitHub → `PrState`: `prSeenOf` (`plan/upgrade-read.ts:19`) maps state + `isDraft`; no green.
