# Phase 5 preflight — standing go in settings

Scaled small: one parser, one doctor check, two crew commands, prose. Recon read the seam in full.

## Findings that change the plan

1. **The phase's evidence string is refused.** `--evidence "self-approved per settings crew.self-approve"`
   has no date, link, backticks or path, so `hasEvidence` (`T/core/checkbox.ts:4`) fails and
   `checkEvidence` (`T/phases/tick.ts:57`) refuses the tick. Use
   `"self-approved per docs/specs/_playbook/settings.md crew.self-approve, <YYYY-MM-DD>"`.
2. **Two homes for the default caps.** `DEFAULT_CAPS` (`T/crew/run-state.ts:9`) already says 3/2; the
   new `crew` defaults would say it again (principles §8). run-state takes its defaults from settings.
3. **Unknown self-approve kinds would be parsed twice** if the doctor re-reads raw frontmatter on its
   own. One helper in settings.ts splits a raw list into known `GateKind`s and unknown words; the parser
   keeps the kinds, the doctor (`T/doctor/settings.ts:16`) errors on the unknown ones.
