## Reuse

- `readySet` itself answers "ready in a workspace": rerun it on a copy of the base state with that
  workspace's ticked phases marked done. No reason-string parsing.
- `pathUsage` + the shared-path filter in `undeclaredOverlaps` → `sharedPaths`.
- `scanWorkspaces` (phase 2) for scans and counts; `listSpecs` + `loadSpecState` for workspace states;
  `loadNodes` for specs that exist only on a branch.
- Factories: `specFixture`, `boardInputs`, `readyRow`, `flightRow`, `board` (`tests/board-factories.ts`).
