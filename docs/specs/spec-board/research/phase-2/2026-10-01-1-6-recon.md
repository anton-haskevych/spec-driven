## Testing-issue estimate

- **Missing harness:** no async stub, no worktree helper, no fixtures for `worktree list` /
  `for-each-ref`. All named deliverables; build them first.
- **Size caps:** every touched file is far under 250 lines (largest `tests/infer-spec.test.ts`, 102).
- **Impure tangles:** `specsInPlay` mixes git calls and parsing; the move extracts the parser, so the
  rename case gets a pure test instead of a stub run.
- **Real-git cost:** one test (two worktrees). Use `isolatedAsyncRunner` (ledger
  `gotcha-code-under-test-that-spawns-git-needs-the-isolated-runner`). Compare paths after
  `realpathSync` (macOS `/var` → `/private/var`).
- **Smell to avoid:** `git status` paths are repo-root relative in porcelain; `diff --name-only` too.
  Both feed `locateSpecFile(join(worktreePath, p))`.
- **Open for preflight:** where the orchestration lives (list → for-each-ref → rev-list → classify →
  merge-base check → changes) — none of the three named files owns it; and whether the main checkout's
  "uncommitted only" holds when it sits on a feature branch.
