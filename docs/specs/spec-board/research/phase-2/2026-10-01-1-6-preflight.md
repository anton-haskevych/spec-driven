## Findings that change the plan

1. **`parsePorcelainZ` does not exist.** The parser is the private `uncommittedPaths` at
   `context/infer-spec.ts:28-37`. Item 2 is move + rename + export, and the rename/copy case gets a pure
   test in `tests/core-git-status.test.ts` (today it is only reachable through a stubbed
   `specsInPlay`, `tests/infer-spec.test.ts:91-101`).
2. **The scan pipeline has no home.** list → `for-each-ref` → `rev-list` → classify → merge-base check →
   changes spans the three named files, and Phase 3's `board/load.ts` is a composer of one call per
   source (`decision-board-inputs-types-apart-from-loader`). Leaving the pipeline for Phase 3 would put
   source logic in the composer. Add `workspaces/scan.ts` with
   `scanWorkspaces(git, runner, baseSha, forceLive) → Promise<Result<WorkspaceScanResult>>`; the one
   real-git test drives it.
3. **"The main checkout runs only the uncommitted query" is a special case of a general rule.** The
   committed diff only finds something when the worktree has commits not on base. Rule: the committed
   query runs iff the branch is ahead (> 0) or the detached head is unmerged; the main checkout is always
   in `forceLive`-equivalent position (never counted merged). A main checkout on `main` (CRM today:
   `main 0 0`) gets only the uncommitted query, as the spec says, and one sitting on a feature branch no
   longer loses its committed docs. Same rule covers W1's fresh worktree (0 ahead, forced live →
   uncommitted only).
4. **`diff --name-only` without `-z` quotes non-ASCII paths** (`core.quotePath`), and `isSpecDocPath`
   (`core/spec-folders.ts:51`) would then miss them. Use `diff --name-only -z` and split on `\0`, like
   `snapshot.ts:49`.
5. **`unknown-base` needs I/O, `classifyWorkspaces` must stay pure.** Pass the merge-base verdicts in:
   `classifyWorkspaces(workspaces, { aheadBehind, unmergedDetached, noMergeBase, forceLive })`. The scan
   runs `merge-base <base> <head>` (exit 1 → no merge base) for branches ahead > `UNKNOWN_BASE_AHEAD`
   before classifying, and again for a workspace whose diff fails; exit 1 → `unknown-base`, otherwise
   `unreadable`.
