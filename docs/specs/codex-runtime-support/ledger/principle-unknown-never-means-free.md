# Unknown evidence cannot release work

Per-source coverage accompanies normalized sessions. Failed or incomplete native discovery never means empty; missing threads never mean successful completion. Preserve healthy-source rows. Rejected: flatten every source failure into empty or lose all good data. Claim and tree policies require the coverage appropriate to their decision.
