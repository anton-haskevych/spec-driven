## Version and compatibility constraints

- Root dev types and CI are 1.4.2; local executable is 1.4.4. New APIs must pass installed types and actual CI-version checks, or declare a scoped version-floor amendment. Do not silently assume types/CI match the local runtime.
- 1.4.4 changes close-event/handshake behavior and strengthens ws compatibility, including auth/handshake options and payload limits. For this narrow local probe native WebSocket plus bounded JSON messages is sufficient; no import from ws is justified.
- Direct stdio app-server remains a distinct supported Codex transport from `app-server proxy`. The earlier proxy timeout is not evidence against direct stdio.
- No Bun process API establishes Codex disconnect survival, approval handling or cancellation of remote descendants. Those remain controlled native lifecycle probes.
